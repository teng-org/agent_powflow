# ADR-012：Powflow Console 事务日志中心演进与落地

- 状态：Accepted
- 日期：2026-03-06
- 决策者：Agent Powflow 核心开发组
- 关联：`ADR-011`、`ADR-010`

## 背景
`ADR-011` 完成了 Console 的全量接口 IA 规划，但在实际施工中，事务日志中心暴露了以下问题：

1. 历史查询与实时监听混用，操作心智不清晰。
2. 风险统计卡（3日警告/错误/严重）与下方日志表口径不一致。
3. 日志表布局抖动、列间距不稳定、长文本挤压影响可读性。
4. 风险筛选、快筛、保存视图等能力缺乏闭环反馈。
5. 缺少低成本调试链路，定位“数字有、结果空”问题效率低。

因此需要在不破坏整体 IA 的前提下，对“事务日志中心”做专项演进。

## 决策
采用“模式分离 + 口径统一 + 交互闭环 + 可调试”的增强策略：

1. 模式分离：历史查询与实时监听互斥。
2. 口径统一：外层卡片与内层风险卡均基于 3 日风险统计口径。
3. 风险联动：风险卡支持多选合并筛选，并可取消。
4. 表格稳定：固定列宽、缩略显示、去重与唯一 key，消除渲染与布局抖动。
5. 操作闭环：快筛、保存视图、应用/删除反馈、详情抽屉、仅看新增。
6. 可调试：前端可开关的日志链路调试输出。

## 自 ADR-011 以来的显著功能变更

### 1. 事务日志中心模式化
1. 新增 `历史查询 / 实时监听` 切换。
2. 实时模式自动轮询；历史模式禁止静默轮询。
3. 切换到历史模式会立即停止实时轮询并执行一次显式查询。

### 2. 风险统计与风险联动增强
1. 外层“事务日志”卡片改名并保留 3 日风险总数展示。
2. 内部 `3日警告/3日错误/3日严重` 改为可点击筛选卡片（数量为 0 时禁用）。
3. 支持多卡片同时激活，合并结果展示。
4. 风险级别归一：`warning` 统一映射为 `warn`。
5. 风险筛选启用时，结果按严重级降序（`critical > error > warn`）。
6. 增加“已隐藏 x 条记录”与当前风险筛选说明。

### 3. 日志列表稳定性与可读性
1. 修复重复 key 警告：列表渲染 key 强制唯一化。
2. 日志聚合增加指纹去重（避免重复展示）。
3. 日志表改为固定列宽 `colgroup`，并压缩列间距。
4. `message` 列强制缩略（ellipsis）+ hover 全文。
5. 修复排序：优先按时间戳数值排序，避免字符串时间错序。

### 4. 筛选体系增强
1. 新增快筛：`仅失败状态`、`仅鉴权失败`、`仅任务异常`。
2. 风险筛选与当前筛选规则叠加，不强制重置用户筛选。
3. 新增时段筛选（`periodStart / periodEnd`，支持跨天区间）。

### 5. 视图能力（保存/应用/删除）
1. 支持保存当前筛选视图到本地存储（`localStorage`）。
2. 支持下拉选择并应用已保存视图。
3. 支持删除选中视图。
4. 新增轻提示：保存/应用/删除后给出短反馈文案。

### 6. 实时体验增强
1. 新增“仅看新增”（仅实时模式可用）。
2. 新到日志短时高亮。
3. 支持行点击，打开日志详情抽屉查看结构化字段。

### 7. 可调试能力
1. 增加前端调试开关：`localStorage.setItem('powflow:logDebug','1')`。
2. 输出关键链路：拉取参数、来源数量、级别分布、风险筛选命中、最终展示数。

## 关键实现文件
1. `apps/web-admin/src/components/MonitorOverview.vue`
2. `apps/web-admin/src/composables/useMonitorAdmin.js`

## 兼容性与影响
1. 不变更后端核心日志模型，仅增强前端聚合与交互。
2. 不影响其他菜单域路由与权限模型。
3. 日志视图保存为前端本地态（浏览器级），不跨账号同步。

## 已知边界
1. 视图能力当前为本地存储，未接入服务端视图模板。
2. 快筛规则仍为固定策略，尚未开放可配置规则中心。
3. 风险口径仍依赖 execution 侧 3 日统计接口；跨服务统一口径仍可继续深化。

## 后续建议（P1）
1. 视图服务端化：支持租户级共享视图模板与权限控制。
2. 风险统计全链路统一：将 execution/chat 统一入同一统计流水口径。
3. 新增“导出当前筛选结果（CSV）”与“审计快照 ID”。
4. 详情抽屉增加原始 payload（脱敏）与关联请求链路跳转。

# Console Workflow 管理 v1

- 日期：2026-08-03
- 状态：已实现并通过单元测试、生产构建和真实浏览器验收

## 1. 目标与边界

统一 Console 现在提供租户级 Workflow 管理入口，覆盖 Control Plane 已有的草稿、校验、不可变发布版本、归档与删除 API。该页面负责定义治理，不直接执行工作流；Run 仍只能绑定已发布版本，不能读取正在修改的草稿。

## 2. 页面能力

“智能体 → 工作流管理”包含三个可定位区段：

1. **工作流**：加载当前租户列表，展示状态、最新版本和草稿修订号，可选择已有工作流或建立新草稿；
2. **草稿编辑**：编辑名称、说明、Workflow DSL 和 Canvas Layout；保存时携带 `expected_revision`，拒绝覆盖其他管理员的新修订；
3. **发布版本**：展示版本号、SHA-256 checksum、发布人和发布时间，并可查看不可变 DSL/layout 快照。

生命周期操作遵循后端不变量：

- 本地 JSON 语法错误在发请求前阻断；
- 服务端校验错误、警告、建议以及关联节点/边按结构展示；
- 发布前二次确认并生成新版本；
- 归档后草稿冻结；
- 永久删除仅对已归档工作流开放，并再次确认；
- 保存、校验、发布、归档后重新读取权威详情和版本列表，避免 UI 保留过期状态。

## 3. 实现结构

- `useWorkflowAdmin.js`：页面状态、JSON 解析、API 编排、乐观锁修订和生命周期刷新；
- `WorkflowManagementPage.vue`：列表、编辑器、校验结果、版本审计和危险操作交互；
- `useConsoleState.js`：工作流管理页面及三个区段的统一导航注册；
- `App.vue`：异步页面装载，避免继续放大 Console 主入口包；
- `ConsoleTopNav.vue`、`ConsoleSideNav.vue`：桌面侧栏和窄屏横向导航。

## 4. 响应式与交互约束

- 1280px：左侧领域导航与主内容并列；
- 820px：领域导航变为横向滚动条，编辑器和版本详情单列；
- 390px：顶栏分为品牌/退出与一级导航两行，所有容器 `scrollWidth == clientWidth`；
- 高频导航不添加阻塞动画；可按压控件提供 140ms `transform` 反馈；
- `prefers-reduced-motion` 下移除缩放反馈，只保留短颜色变化；
- 页面错误使用可见反馈，危险操作不依赖颜色作为唯一提示。

## 5. 验证证据

- Console Vitest：23/23；其中 Workflow composable 5 项覆盖 JSON 拒绝、加载/乐观锁保存、无效 JSON 不请求后端、发布刷新和归档后删除；
- Vite 生产构建：78 modules，工作流页面独立异步 chunk；
- 浏览器：390px、820px、1280px 均无横向溢出；创建态、已发布态、生命周期按钮和不可变版本详情可访问；浏览器 error 日志为空；
- Endpoint catalog：230/230；工作流 API 无新增悬空或未登记路由；
- Stack smoke：真实 PostgreSQL 下完成创建、发布、checksum、版本读取、归档、删除和严格清理。

## 6. 后续边界

当前编辑器是结构化 JSON 管理界面，不是节点拖拽画布。下一阶段应在不改变本页生命周期契约的前提下增加图形化编辑器，并优先扩展运行时 fan-out/join、确定性失败聚合及人工审批的持久化暂停/恢复。

# Agent Powflow v0.1.0-beta.1

发布日期：2026-08-11
发布级别：邀请制 Pilot / Beta

## 发布目标

这是首个可供小范围团队闭环试用的产品化版本。它把账户与工作空间、知识库、RAG2、智能体、Workflow、Skill、MCP 和 API 发布整合到同一控制面，并提供 Docker 化部署与自动化质量门禁。

## 已验证链路

- 注册/登录、工作空间选择和邀请接受
- 文档上传、解析、切片、嵌入、索引与检索
- Dense + BM25 + RRF + Reranker + Parent Context
- RAG 候选构建、五条 Golden Set 评测、激活、真实检索和回滚
- 智能体创建、发布、连续会话与并发调用
- Workflow 编辑、校验、发布与执行
- API Deployment、自动签发密钥、调用、限流/撤销和日志

RAG 闭环候选版本的离线 Recall@10、MRR@10、NDCG@10 均为 0.8；候选激活与回滚后均通过真实混合检索验证。

## 已知边界

- 当前定位为 5–20 名明确用户的受控试用，不是公共 SaaS GA。
- 大模型供应商长尾延迟仍可能超过两分钟，需要按实际模型和容量设定超时与并发。
- 生产部署前仍需完成公网入口加固、TLS、备份恢复演练、容量压测、告警接收和合规评审。
- Beta 期间部分管理接口和 UI 信息架构仍可能调整。

## 升级与回滚

首次部署应从 `.env.production.example` 生成生产配置并执行密钥校验。数据库迁移由服务启动链路按版本顺序应用；升级前必须完成 PostgreSQL、Qdrant、MinIO 和配置备份。

应用层回滚可切回前一镜像版本；RAG 索引使用工作台内的版本回滚能力。数据库迁移回退必须依据对应运维手册执行，不得直接删除迁移记录。
